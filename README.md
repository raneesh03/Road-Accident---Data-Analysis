Road Accident Data Analysis Using Python

Project Overview

This project analyzes road accident data using Python to identify patterns in accident severity, casualties, weather conditions, road types, vehicle types, and light conditions.

Objectives

- Analyze road accident trends over time.
- Examine accident severity and casualty counts.
- Investigate weather and road surface conditions.
- Compare accidents in urban and rural areas.
- Visualize important findings using Matplotlib.

Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

Research Questions

1. How many accident records are in the dataset?
2. Which year and month recorded the most accidents?
3. Which accident severity occurs most frequently?
4. Do more accidents occur in urban or rural areas?
5. Which weather and road surface conditions have the most recorded accidents?
6. Which vehicle types appear most frequently?
7. Which districts have the highest accident counts?
8. How do casualties vary by accident severity?

Project Workflow

1. Data loading
2. Data cleaning
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Findings and conclusions

Key Findings

1.Accident Trends: Identify the year and month with the highest number of recorded road accidents.

2.Accident Severity: Determine which accident severity category occurs most frequently.

3.Urban vs Rural: Compare accident frequency between urban and rural areas.

4.Weather Conditions: Identify the weather conditions associated with the highest number of recorded accidents.
How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the cells in order.
